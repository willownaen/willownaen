## 零经验怎么找产品实习？我的三个月实习复盘

### 第一步：怎么学？

**时间充足：** B站黑马产品经理课程，从零到一打基础，内容完整全面。

**时间有限（速成）：** 找一门把核心概念串一遍的课，**边听边练** —— 照着手机里某个真实 App 的交互画出原型，包装成项目写进简历。B站也可以直接搜「产品实战项目跟练」或「原型实战项目跟练」。

**重点学这三块：**
- 需求分析
- PRD 撰写
- 原型设计（Axure / Figma / 墨刀）

### 第三步：搞懂真实的产品工作流程

产品工作分五个阶段，是一个持续循环：

#### 1. 项目启动期
决定产品大方向（做养老还是做宠物等），一般由高管决定，实习生较少接触。

#### 2. 项目准备期
- **需求收集**：来源有两类——产品经理自己做竞品分析 / 收集用户反馈，以及领导、运营等内部同事提出的需求
- **需求分析**：评估需求可行性和优先级，整理成功能清单
- **流程设计**：根据功能清单设计具体交互流程（比如登录流程的每一步）

#### 3. 执行期
- **原型设计**：画出功能的具体形态
- **需求文档（PRD）**：逻辑清晰的 PRD 能省掉其他同事大量沟通成本
- **需求评审**：产品上台讲功能，开发 / 测试 / 数据同事提问。安卓和 iOS 一般分开审。**被问蒙是常态**，问完立刻想解决方案同步就好。

#### 4. 跟进期
- 把控进度、协调资源
- 开发和测试对需求有分歧时，产品来拍板最终方案
- 开发延期时，决定是砍需求推到下个版本，还是加班赶工
- **同时**：这个阶段要并行准备下一个版本的原型，不会有人闲着

#### 5. 收尾期
- 测试验收
- 关注上线后的用户反馈
- 根据反馈规划下一个版本的优化方向，进入下一个循环
